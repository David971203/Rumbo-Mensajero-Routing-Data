# Rumbo Mensajero Routing Data

Paquete de enrutamiento offline de Cuba para Rumbo Mensajero. El archivo `cuba-valhalla.tar` contiene un grafo Valhalla generado desde el extracto de Cuba de Geofabrik/OpenStreetMap.

## Datos y licencia

Datos © OpenStreetMap contributors, disponibles bajo la Open Database License (ODbL): https://www.openstreetmap.org/copyright

El software Valhalla se distribuye bajo licencia MIT: https://github.com/valhalla/valhalla

Los archivos publicados incluyen un manifiesto JSON con la fuente, fecha, tamaño y SHA-256 del paquete.
